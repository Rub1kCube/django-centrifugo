Installation
============

Install ``django-centrifugo`` from PyPI with your preferred package manager.

.. tabs::

   .. tab:: :iconify:`material-icon-theme:uv` uv

      .. code-block:: console

         uv add django-centrifugo

   .. tab:: :iconify:`devicon:poetry` Poetry

      .. code-block:: console

         poetry add django-centrifugo

   .. tab:: :iconify:`devicon:pypi` pip

      .. code-block:: console

         python -m pip install django-centrifugo
